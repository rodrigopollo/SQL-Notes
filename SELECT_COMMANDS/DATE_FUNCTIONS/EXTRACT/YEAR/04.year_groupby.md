# YEAR — Total vendido no ano de 2025

## Tabela utilizada
```
payments
+------------+---------------------+--------+
| payment_id | payment_date        | amount |
+------------+---------------------+--------+
| 1          | 2024-01-15 10:30:00 |  10.00 |
| 2          | 2025-03-22 18:45:00 |  20.00 |
| 3          | 2025-07-05 09:00:00 |  30.00 |
| 4          | 2026-09-10 14:20:00 |  40.00 |
| 5          | 2026-02-01 12:10:00 |  50.00 |
+------------+---------------------+--------+
```

## Query
```sql
SELECT
    EXTRACT(YEAR FROM payment_date) AS ano,
    COUNT(payment_id)               AS qnt_pagamentos,
    SUM(amount)                     AS tot_vendido
FROM payments
WHERE
    EXTRACT(YEAR FROM payment_date) = 2025
GROUP BY
    EXTRACT(YEAR FROM payment_date)
ORDER BY ano;
```

## Resultado
```
+------+----------------+-------------+
| ano  | qnt_pagamentos | tot_vendido |
+------+----------------+-------------+
| 2025 | 2              | 50.00       |
+------+----------------+-------------+
```
Em 2025 houveram 2 pagamentos que totalizaram R$ 50,00.

## O que cada parte faz
- `EXTRACT(YEAR FROM payment_date) AS ano` — extrai o ano de cada pagamento.
- `COUNT(payment_id) AS qnt_pagamentos` — conta quantos pagamentos ocorreram no ano filtrado.
- `SUM(amount) AS tot_vendido` — soma o valor de todos os pagamentos do ano filtrado.
- `WHERE EXTRACT(YEAR FROM payment_date) = 2025` — filtra apenas os registros cujo ano é 2025, 
antes de qualquer agrupamento.
- `GROUP BY EXTRACT(YEAR FROM payment_date)` — agrupa os registros pelo ano para que `COUNT` e `SUM` 
funcionem corretamente.
- `ORDER BY ano` — ordena o resultado pelo ano.
